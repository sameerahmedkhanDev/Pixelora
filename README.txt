PIXELORA WEBSITE
================
Open index.html in Chrome, Edge, Safari or Firefox.
Keep index.html and the "assets" folder together (same folder).

Edit in index.html (search for these):
  [YOUR EMAIL] [YOUR NUMBER] [YOUR LINKEDIN PAGE]  -> your contact details
  YOURDOMAIN.com                                    -> your real domain
  YOUR_FORM_ID                                      -> free form ID from formspree.io
  "View project" buttons                            -> swap GitHub links for live site links

To host it free: upload this whole folder to Netlify, Vercel or GitHub Pages.
